# Preparación para el examen B1 de inglés

Curso web de preparación para una prueba B1 de inglés, con prácticas, explicaciones y un plan progresivo de estudio:

- `index.html`: estructura y accesos al examen y al método de estudio.
- `logo.svg`: identidad visual de la aplicación y favicon para el despliegue.
- `styles.css`: estilos y diseño adaptable.
- `app.js`: banco de más de 200 preguntas, rondas de práctica, repaso de errores y seguimiento por tema.
- `study-guide.js`: ruta de estudio priorizada en cuatro etapas, con fundamentos, gramática, vocabulario, preposiciones, phrasal verbs, conectores y práctica de lectura, escritura, escucha y conversación. Incluye un plan de 8 semanas, criterios de autoevaluación, práctica integrada de 38 preguntas y un panel de estudio con verbos diarios, tiempo semanal, racha y progreso por etapa.
- `verb-forms.js`: referencia de 187 verbos, patrones, plan de estudio, índice y ejercicios autocorregibles.
- `business-english.html`, `business-english.css` y `business-english.js`: curso complementario de inglés B1 para el trabajo, con 12 lecciones, secciones desplegables, tablas largas con desplazamiento interno, 20 términos de vocabulario por tema, linkers y una referencia de 29 fórmulas gramaticales esenciales con ejemplos y uso en inglés. Incluye un plan de ocho semanas, repaso y proyecto final. Se abre desde la portada principal.

La guía recorre gramática, vocabulario y las cuatro destrezas: lectura, escritura, escucha y conversación. El material ayuda a prepararse, pero no es un examen oficial ni otorga una certificación.

## Ejecutar

Abre `index.html` en un navegador. No requiere instalar dependencias ni compilar. Para probarlo desde VS Code también puedes servir esta carpeta con una extensión de servidor local.

Las prácticas y el avance se conservan en el navegador. Las tipografías se cargan desde Google Fonts cuando hay conexión a internet.
